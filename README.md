# Personal Portfolio & Blog

A modern portfolio and blog website built with Vue 3, TypeScript, and Vite.

## Features

- 🎨 **Portfolio Showcase** - Display your projects with detailed views
- 📝 **Blog Platform** - Share your thoughts and insights
- 🔒 **Admin Dashboard** - Manage portfolio projects and blog posts
- 📱 **Responsive Design** - Built with Tailwind CSS for all device sizes
- ⚡ **Fast Performance** - Powered by Vite for quick loading times

## Tech Stack

- **Frontend Framework**: Vue 3 with Composition API
- **Type Safety**: TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **State Management**: Pinia
- **Routing**: Vue Router
- **Rich Text Editing**: TinyMCE
- **Animations**: GSAP, AOS, Vue3-Lottie
- **3D Effects**: Three.js
- **Date Formatting**: Day.js
- **Markdown Parsing**: Marked
- **Testing**: Vitest

## 📋 Prerequisites

- Node.js (v18 or higher)
- npm or yarn

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/eminisolomon/portfolio.git
cd portfolio
```

1. Install dependencies

```bash
npm install
# or
yarn install
```

1. Start the development server

```bash
npm run dev
# or
yarn dev
```

1. Build for production

```bash
npm run build
# or
yarn build
```

## 📂 Project Structure

```code
src/
├── assets/         # Static assets like images and CSS
├── components/     # Reusable Vue components
├── composables/    # Vue composition functions
├── config/         # Configuration files
├── constants/      # Constants and static data
├── interfaces/     # TypeScript interfaces
├── layouts/        # Layout components
├── pages/          # Page components
├── routes/         # Vue Router setup
└── stores/         # Pinia stores for state management
```
